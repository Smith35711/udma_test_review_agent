# test_project 缺陷标准清单（人工核对）

用途：与检视产物逐条比对，衡量**检出率**、**误报率**与**定级准确度**。

比对口径：
- 命中判据是「指出了该处存在该类问题」，不要求措辞一致；
- 同一处问题被拆成多条、或多处同类问题被合并成一条，均按命中计；
- 等级允许 ±1 级偏差，偏差超过一级才计入定级错误；
- B 节是**诱饵**（看着可疑但实际正确），报告出来即计为误报。

行号以当前文件内容为准。
